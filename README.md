## 🌟 Overview

**CampusSkillX (by Linksy)** is an **interactive web platform** that empowers students to explore, develop, and showcase their skills in a structured, visually engaging way.

Built with **React + Tailwind CSS + Framer Motion**, it’s designed for **students, educators, and tech enthusiasts** to make learning, hackathons, and skill development seamless and fun.

---

## ✨ Key Features

| Feature | Description |
|----------|-------------|
| 🎨 **Interactive Hero Page** | A visually striking landing section with Framer Motion animations and scroll effects. |
| 🧠 **Skill Development Tracking** | Plan, learn, and showcase your skills (coming soon). |
| 🏆 **Hackathon Showcase** | Dedicated section for active and past hackathons with details and external links. |
| 📱 **Responsive Design** | Optimized for desktop, tablet, and mobile. |
| 🔗 **Smooth Navigation** | Anchor-based scrolling and dynamic UI transitions. |
| 👥 **Role-Based Layouts** | Future-ready for Students, Mentors, and Educators. |
| ⚡ **Modern UI/UX** | Built using React, TailwindCSS, and Framer Motion for a clean, modern interface. |
| 🔮 **Future Expansion** | Backend integration planned for leaderboards, analytics, and skill insights. |

## 🏗️ Tech Stack

| Layer | Technology | Purpose |
|-------|-------------|----------|
| 🌐 Frontend | **React + Vite** | Core framework for app logic and routing |
| 🎨 Styling | **TailwindCSS** | Responsive, utility-first styling |
| 🎞️ Animation | **Framer Motion** | Smooth motion and transitions |
| ⚙️ Build Tool | **Vite** | Super-fast development environment |
| ☁️ (Planned) | **Supabase / Firebase** | Backend, database, and authentication |
| 📊 (Planned) | **Recharts / Chart.js** | Skill analytics and insights dashboard |
